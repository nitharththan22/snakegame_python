# 🐍 Snake Game

A simple Snake game built using Python and the Turtle module. Move the snake, eat food, and grow while avoiding collisions!

## 🎮 Features
- Classic Snake gameplay with movement controls.
- Random food generation.
- Score tracking with a high score system.
- Collision detection for borders and the snake's body.
- Game reset upon collision.

## 🛠️ Requirements
- Python 3.x
- `turtle` module (built into Python)
